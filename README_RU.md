**Ammora** — продвинутая экономическая и финансовая модификация для **Minecraft NeoForge 1.21.1**.  
Мод превращает статичную экономику серверов в **живой децентрализованный рынок** на базе математической модели автоматического маркетмейкера (**AMM Bonding Curve**).

Забудьте о бесконечных деньгах с автоматических ферм золота или железа: цены формируются реальным балансом спроса и предложения, реагируют на проскальзывание в крупных партиях, защищены от инфляции утилизационным сбором за перепроизводство и полностью автоматизируются через **Create** и **CC: Tweaked (ComputerCraft)**.

---

## Ключевые возможности

- **Единая стабильная валюта (CBX)**: Серверная цифровая валюта без инфляции, используемая на терминале, вендинговых автоматах, планшете и P2P переводах.
- **Математическое ценообразование AMM**: Мгновенный расчет спотовых цен на основе фактических складских запасов биржи.
- **Интерактивные японские свечи (OHLCV)**: Встроенные графики котировок с объемом торгов, зумом, таймфреймами и отображением событий.
- **Обезличенные металлические счета (ОМС)**: Инвестируйте в сырьевые деривативы (золото, алмазы, незерит) без физических складов с мониторингом нереализованного PnL.
- **Серверные отложенные ордера**: Создавайте заявки `BUY_LIMIT` и `SELL_LIMIT`. Сервер автоматически исполнит их при достижении целевой цены.
- **Срочные контракты и фьючерсы**: Выполняйте государственные и корпоративные контракты с фиксированной ценой, залогом и очками репутации.
- **Торговые автоматы игроков (Rust-Style)**: Устанавливайте вендинговые аппараты на 5–10 слотов с апгрейдами вместимости (до 1024 шт./слот), модулем спутниковой связи и привязкой к корпоративному счету.
- **Торговый планшет и эскроу-заявки (RFQ)**: 8 вкладок управления торговлей: глобальный маркет, каталог магазинов, живые аукционы, скупка с резервированием в эскроу, квесты сообщества, управление корпорацией, буфер доставок и история.
- **Корпорации и совместные счета (Companies & Joint Accounts)**: Создавайте организации с общей казной, трёхуровневой ролевой моделью (`OWNER`, `MANAGER`, `MEMBER`), суточными лимитами расходов и прозрачным журналом финансового аудита (Ledger). Переключайтесь между личным и корпоративным счетом в 1 клик в планшете и холодном кошельке.
- **Аукционный дом реального времени (Live Auctions)**: Проводите открытые торги с динамическими ставками, защитой от снайпинга (+60 секунд в финале), опцией моментального выкупа и заморозкой средств в эскроу.
- **Интерактивная доставка (Пчела-курьер)**: Доставка покупок из планшета с визуализированным полетом пчелы-курьера прямо в руки игроку (с автоматическим сохранением в буфер SQLite при оффлайне или переполнении).
- **Безопасный прямой обмен P2P**: Двусторонний торговый интерфейс с защитой от мошенничества (таймеры подтверждения, сброс готовности при изменении предметов/сумм).
- **Холодный кошелек**: Карманный NFC-кошелек с поиском игроков поблизости, моментальными переводами без комиссии, поддержкой корпоративного счёта и 30-дневной выпиской.
- **Физическая валюта и банкоматы (ATM)**: Банкноты номиналом 10, 100 и 1000 CBX, пачки денег и декоративные денежные блоки со сбалансированными рецептами крафта. Двухблочный банкомат в индустриальном стиле для снятия и внесения наличных, автокоррекции сумм, моментального расчета купюр и контроля корпоративных суточных лимитов.
- **Интеграция с Create и CC: Tweaked**:
  - **Create**: Скорость вращения кинетических валов ускоряет погрузку товаров; Display Link выводит живые котировки на табло; интерактивные 3D Ponder сцены.
  - **CC: Tweaked**: Полнофункциональный Lua API для написания торговых ботов, панелей мониторинга и автоматических систем сбыта.
- **Поддержка датапаков (Datapacks)**: Добавление любых модовых предметов, контрактов и рыночных событий через стандартные JSON датапаки (`data/ammora/...`).
- **Консоль оператора и аудит (/ammora admin)**: Полнофункциональная GUI-панель для администраторов: мониторинг и управление балансами игроков, настройка стоимости регистрации компаний, запуск макроэкономических кризисов и бумов, тонкая подстройка кривых AMM и аудит всех торговых сделок.

## Экономическая модель

### 1. Формула спотовой цены
Текущая спотовая цена $P(S)$ зависит от текущих запасов $S$:

$$P(S) = P_0 \times \left(\frac{S_{target}}{S}\right)^k$$

- $P_0$ — базовая равновесная цена в **CBX**.
- $S_{target}$ — нормативный объем склада.
- $S$ — фактическое количество товара на складе биржи.
- $k$ — коэффициент эластичности ($0.75 - 0.95$).

### 2. Проскальзывание цены (Slippage)
При покупке крупной партии каждая единица покупается из чуть более опустевшего склада. Расчет ведется по интегралу кривой AMM:
- В GUI отображаются спот-цена, средневзвешенная цена и итоговая сумма.
- Кнопка `MAX` использует алгоритм бинарного поиска для вычисления максимального доступного количества.

### 3. Экологический сбор за перепроизводство
Если запасы превышают максимальную емкость склада $S_{max}$, цена уходит в минус:

$$C_{disposal} = \alpha \times \left(\frac{S - S_{max}}{S_{target}}\right)^2$$

В этот момент продавец не получает деньги, а платит бирже за утилизацию мусора, что исключает крах экономики от гиперферм.

### 4. Торговые ранги и комиссии

| Уровень | Ранг | Очки REP | Биржевая комиссия |
| :---: | :---: | :---: | :---: |
| **I** | Новичок | 0 – 99 | 2.0% |
| **II** | Трейдер | 100 – 499 | 1.6% |
| **III** | Брокер | 500 – 1 999 | 1.2% |
| **IV** | Инвестор | 2 000 – 9 999 | 0.8% |
| **V** | Кит (Whale)| 10 000+ | **0.5%** |

*1 очко REP начисляется за каждые 10 CBX торгового оборота.*

## Блоки и предметы

| Предмет / Блок | Описание |
| :--- | :--- |
| **Биржевой Терминал** | Главная станция трейдера: свечные графики, ордербук, ОМС, лимитные ордера, контракты, настройка редстоуна. |
| **Банкомат (ATM)** | Двухблочный аппарат для внесения и снятия наличных купюр CBX с контролем суточных лимитов сотрудников. |
| **Торговый Док** | Автоматизированный интерфейс сдачи/покупки предметов. Подключается к воронкам, конвейерам и валам Create. Поддерживает привязку к компании (Shift+ПКМ). |
| **Логистический Блок Закупки** | Закупщик ресурсов с биржи в локальные сундуки с настраиваемым размером партии, защитой Stop-High и переключением списания с личного или корпоративного счёта. |
| **Торговый Автомат** | Персональный вендинговый магазин игрока с индивидуальными ценниками, апгрейдами, спутниковой связью и автоматическим перечислением выручки в казну привязанной компании. |
| **Холодный Кошелек** | Карманный гаджет для просмотра баланса CBX, истории транзакций, P2P переводов и переключения между личным и корпоративным счётом. |
| **Торговый Планшет** | Глобальный маркетплейс на 8 вкладок: удаленная покупка в магазинах, живые аукционы, создание RFQ-заявок, квесты сообщества, управление корпорацией и доставка пчелой-курьером. |
| **Банкноты CBX** | Физические наличные деньги (10, 100, 1000 CBX), пачки и декоративные денежные блоки с полным циклом крафта. |

## Датапаки (Datapacks)

Ammora полностью настраивается через ванильные датапаки Minecraft:

```json
{
  "resourceId": "create:brass_ingot",
  "displayName": "Латунный слиток",
  "basePrice": 28.0,
  "targetReserve": 6000.0,
  "currentStock": 6000.0,
  "elasticity": 0.85,
  "maxReserve": 10000.0,
  "disposalAlpha": 20.0,
  "feeRate": 0.02,
  "minPriceFloor": 0.20
}
```

*Подробнее в [Гайде по датапакам](docs/DATAPACKS_GUIDE_RU.md).*

## CC: Tweaked Lua API

Подключите компьютер к любому блоку биржи:

```lua
local exchange = peripheral.find("exchange_terminal")

local quote = exchange.getQuote("minecraft:iron_ingot")
print(string.format("Спот железа: %.2f CBX | Покупка: %.2f CBX", quote.spotPrice, quote.buyPrice))

local result = exchange.buy("minecraft:iron_ingot", 64)
if result.success then
    print(string.format("Куплено 64 железа за %.2f CBX", result.cbxSpent))
end
```

*Полный справочник методов в [Гайде по ComputerCraft](docs/CC_TWEAKED_GUIDE_RU.md).*

## Панель администратора (/ammora admin)

Для управления экономикой сервера администраторам доступна встроенная панель управления:
```
/ammora admin
```
*Требуется уровень прав оператора (OP level 2+).*

Панель разделена на 4 функциональные вкладки:
1. **Балансы**: просмотр списка всех зарегистрированных игроков сервера с живым поиском по нику или UUID. Оператор может установить точный баланс, начислить или списать CBX, обнулить счёт или воспользоваться быстрыми кнопками (+100, +500, +1000 CBX). Также внизу вкладки настраивается **глобальная стоимость регистрации компании (госпошлина)**. Если игрок на сервере, он получает мгновенное системное оповещение.
2. **События**: запуск макроэкономических кризисов и аномалий (инфляция, золотая лихорадка, падение спроса) с указанием длительности в игровых днях. Активное событие отображается золотой карточкой с возможностью досрочной остановки кнопкой `[⏹ Завершить досрочно]`.
3. **Курсы AMM**: тонкая настройка пулов ликвидности любого биржевого товара в реальном времени. Позволяет вручную скорректировать базовую цену $P_0$, суточный модификатор спроса (+/- %), текущие складские резервы ($S$) или сбросить модификатор в 0%.
4. **Логи сделок**: сводный аудит всех торговых операций на сервере (локальные покупки в автоматах, удаленные заказы с дронами, RFQ-заявки и биржевые ордера). Поддерживает фильтрацию по никам продавца/покупателя и названиям товаров.

## Сборка мода из исходников

Требования:
- **Java 21 JDK**
- Git

```bash
git clone https://github.com/AspisSH/Ammora.git
cd Ammora
./gradlew test
./gradlew build
```

Скомпилированный файл мода находится в `build/libs/ammora-1.21.1-neoforge-1.0.0.jar`.
