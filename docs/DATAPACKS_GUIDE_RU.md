# Руководство по созданию датапаков: Товары, События и Контракты

Ammora позволяет создателям модпаков и администраторам серверов настраивать экономику без правки исходного Java-кода с помощью стандартных **датапаков Minecraft**.

Датапаки автоматически применяются при старте сервера или при выполнении команды `/reload`.

---

## Структура папок датапака

Внутри папки датапака (`world/datapacks/your_pack/` или внутри jar-файла вашего мода):
```text
your_datapack/
├── pack.mcmeta
└── data/
    └── <namespace>/
        └── exchange/
            ├── commodities/           <-- Товары на спотовом рынке
            │   ├── copper.json
            │   └── brass.json
            ├── market_events/         <-- Рыночные события (новости/кризисы)
            │   ├── gold_rush.json
            │   └── tech_boom.json
            └── delivery_contracts/    <-- Срочные контракты и госзаказы
                ├── steel_delivery.json
                └── food_drive.json
```

> [!TIP]
> Файлы можно располагать под любым пространством имен (например, `data/exchange/exchange/commodities/` или `data/my_pack/exchange/commodities/`). Мод автоматически сканирует все активные неймспейсы.

## 1. Настройка товаров (`commodities/*.json`)

Каждый добавленный товар автоматически появляется на **Биржевом Терминале**, **Торговом Доке**, **Блоке Закупки**, в **Торговом Планшете** и в периферии **CC: Tweaked**.

### Пример конфигурации
```json
{
  "resourceId": "create:brass_ingot",
  "displayName": "Латунный слиток",
  "basePrice": 28.0,
  "targetReserve": 6000.0,
  "currentStock": 6000.0,
  "elasticity": 0.85,
  "maxReserve": 10000.0,
  "disposalAlpha": 20.0,
  "feeRate": 0.02,
  "minPriceFloor": 0.20
}
```

### Справочник параметров
| Параметр | Тип | Обязательный | Описание | Значение по умолчанию |
| :--- | :---: | :---: | :--- | :--- |
| `resourceId` | String | **Да** | Идентификатор предмета в реестре (`мод:предмет`). | например `minecraft:iron_ingot` |
| `displayName` | String | Нет | Имя товара в графических интерфейсах. | Локализованное имя из игры |
| `basePrice` | Double | **Да** | Равновесная цена $P_0$ в **CBX** при нормальном объеме склада. | `1.0` - `5000.0` |
| `targetReserve`| Double | **Да** | Нормативный целевой запас склада $S_{target}$. | `500` - `20000` |
| `currentStock` | Double | Нет | Начальный склад при первой инициализации. | Равен `targetReserve` |
| `elasticity` | Double | Нет | Эластичность кривой цены ($k$). | `0.80` (диапазон: `0.70` - `0.95`) |
| `maxReserve` | Double | Нет | Порог переполнения $S_{max}$, выше которого цена падает в минус. | `targetReserve * 1.5` |
| `disposalAlpha`| Double | Нет | Коэффициент жесткости штрафа утилизации $\alpha$. | `15.0` (диапазон: `10.0` - `40.0`) |
| `feeRate` | Double | Нет | Базовая биржевая комиссия со сделки. | `0.02` (2.0%) |
| `minPriceFloor`| Double | Нет | Минимальный пол цены покупки (не может опуститься ниже). | `0.05` CBX |

## 2. Рыночные события (`market_events/*.json`)

События временно меняют котировки ресурсов, влияют на доходность торговли и оповещают игроков бегущей строкой в терминале и сообщениями в чате.

### Пример конфигурации
```json
{
  "id": "gold_rush",
  "title": "Золотая Лихорадка",
  "description": "Обнаружены древние сокровищницы! Огромный приток золота обрушил биржевой курс.",
  "affectedResource": "minecraft:gold_ingot",
  "priceMultiplier": 0.70,
  "durationDays": 2,
  "weight": 10
}
```

### Справочник параметров
| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `id` | String | **Да** | Уникальный строковый ID события. |
| `title` | String | **Да** | Заголовок новости в верхней плашке биржевого терминала. |
| `description` | String | **Да** | Подробный текст новости, рассылаемый игрокам в чат. |
| `affectedResource`| String | **Да** | Ресурс, курс которого подвергается модификации. |
| `priceMultiplier` | Double | **Да** | Множитель цены (например `1.35` — рост на +35%, `0.70` — обвал на -30%). |
| `durationDays` | Integer| Нет | Длительность события в игровых сутках (по 24 000 тиков каждое, по умолч.: 2). |
| `weight` | Integer| Нет | Вес шанса выпадения события при случайной генерации (по умолч.: 10). |

## 3. Срочные контракты (`delivery_contracts/*.json`)

Контракты представляют собой гарантированные заказы на поставку ресурсов, которые игроки могут брать на биржевом терминале.

### Пример конфигурации
```json
{
  "contractId": "bridge_reinforcement",
  "title": "Строительство Великого Моста",
  "resourceId": "minecraft:iron_ingot",
  "targetAmount": 1280,
  "guaranteedUnitPrice": 15.5,
  "collateralCbx": 500.0,
  "deadlineTicks": 48000,
  "rewardRep": 150
}
```

### Справочник параметров
| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `contractId` | String | **Да** | Уникальный ID контракта. |
| `title` | String | **Да** | Отображаемое название заказа. |
| `resourceId` | String | **Да** | Требуемый ресурс для сдачи. |
| `targetAmount` | Integer| **Да** | Необходимое общее количество предметов. |
| `guaranteedUnitPrice`| Double| **Да** | Фиксированная выплата в **CBX** за штуку (не зависит от падения рыночной цены!). |
| `collateralCbx`| Double | Нет | Залог, временно блокируемый при принятии контракта (по умолч.: 0). |
| `deadlineTicks`| Integer| Нет | Срок выполнения в тиках (`24000` = 1 игровой день = 20 минут реального времени). |
| `rewardRep` | Integer| Нет | Дополнительные очки репутации торговца за закрытие контракта. |

---

## Перезагрузка и проверка

1. Выполните команду `/reload` на сервере или в одиночной игре.
2. В консоли отобразятся сообщения:
   ```text
   [Ammora] Loaded X custom commodities from datapacks.
   [Ammora] Loaded Y market events from datapacks.
   [Ammora] Loaded Z delivery contracts from datapacks.
   ```
3. Откройте интерфейс терминала или планшета, чтобы убедиться в появлении предметов.
