# Руководство по локализации и переводу мода Ammora

Данное руководство создано для игроков, переводчиков и создателей модпаков. Оно объясняет, как устроен перевод мода **Ammora**, как перевести его на любой язык мира (**Chinese, German, Spanish, French, Japanese, Ukrainian и др.**) без правки Java-кода, и содержит готовый промпт для нейросетей (**ChatGPT / Claude / DeepSeek**) для мгновенного автоматического перевода.

---

## Расположение языковых файлов

Все переводы хранятся в стандартном формате Minecraft JSON:
```text
src/main/resources/assets/exchange/lang/
├── en_us.json    <-- Международный английский язык (Базовый стандарт)
└── ru_ru.json    <-- Русский язык (Полная локализация)
```

Также перевод можно применять **без сборки мода через обычный Resource Pack (Текстур-пак)** по пути:
```text
your_resourcepack/assets/exchange/lang/<код_языка>.json
```

### Примеры кодов языков:
- Упрощенный китайский: `zh_cn.json`
- Немецкий: `de_de.json`
- Испанский: `es_es.json`
- Французский: `fr_fr.json`
- Украинский: `uk_ua.json`
- Японский: `ja_jp.json`
- Португальский (Бразилия): `pt_br.json`

## Структура ключей локализации

Все ключи строго структурированы по категориям:

| Префикс | Назначение | Пример |
| :--- | :--- | :--- |
| `itemGroup.exchange` | Вкладка в креативном меню | `itemGroup.exchange` |
| `block.exchange.*` | Имена блоков в игре | `block.exchange.exchange_terminal` |
| `item.exchange.*` | Имена предметов в игре | `item.exchange.cold_wallet` |
| `tooltip.exchange.*` | Подсказки при наведении на предмет | `tooltip.exchange.cold_wallet.1` |
| `rank.exchange.*` | Ранги инвесторов (Ур. 0–5) | `rank.exchange.4` (Инвестор / Investor) |
| `commodity.exchange.*` | Короткие биржевые имена активов | `commodity.exchange.minecraft.diamond` |
| `gui.exchange.terminal.*` | Интерфейс биржевого терминала | Вкладки, кнопки СПОТ/ОМС, ордера |
| `gui.exchange.trade.*` | Окно защищенного P2P обмена | Колонки игроков, кнопки фиксации |
| `gui.exchange.wallet.*` | Интерфейс холодного кошелька | Баланс, переводы, список игроков |
| `gui.exchange.dock.*` | Блок закупки ресурсов | Лимиты цен, размер партии |
| `gui.exchange.shop.*` | Торговый автомат игроков | Склад, выручка, улучшения |
| `gui.exchange.market.*` | Торговый планшет (Маркетплейс) | Скупка, буфер доставок на 10 слотов |
| `message.exchange.*` | Сообщения чата и уведомления | Покупка, продажа, ошибки, Anti-Scam |
| `event.exchange.*` | Новости и события экономики | Золотая лихорадка, обвалы шахт |
| `ponder.exchange.*` | Интерактивные сцены Create Ponder | Руководства в 3D кинематике |

## Правила оформления и плейсхолдеры

1. **Плейсхолдеры переменных**:
   - `%s` — строка (например, число CBX или имя игрока/товара).
   - `%d` — целое число (например, количество предметов или уровень ранга).
   - `%%` — знак процента `%` (например, комиссия `2%`).
   *Не удаляйте и не меняйте порядок плейсхолдеров внутри одной строки!*

2. **Цветовые коды Minecraft (`§`)**:
   - `§6` — золотой / янтарный (Industrial Amber)
   - `§a` — зеленый (успех, подтверждение, прибыль)
   - `§c` — красный (ошибка, отмена, расход)
   - `§e` — желтый (предупреждение, готовность)
   - `§7` / `§8` — серый (второстепенный текст, подсказки)
   - `§l` — жирный шрифт

## Готовый Промпт для ИИ (ChatGPT / Claude / DeepSeek)

Скопируйте текст ниже, укажите целевой язык и вставьте содержимое `en_us.json`. Нейросеть мгновенно создаст файл локализации:

```text
Ты — профессиональный локализатор модификаций для Minecraft.
Твоя задача — перевести языковой файл мода "Ammora" (биржа ресурсов ChainBX) с английского (en_us.json) на [УКАЖИ ЦЕЛЕВОЙ ЯЗЫК, например: Упрощенный китайский (zh_cn) / Немецкий (de_de) / Испанский (es_es)].

Правила перевода:
1. Сохраняй цветовую разметку Minecraft (§a, §c, §6, §e, §7, §8, §l) точно там, где она находится в исходнике.
2. Сохраняй все плейсхолдеры (%s, %d, %%) на своих местах.
3. Валюта "CBX" и название "ChainBX" НЕ переводится.
4. Обозначения рангов, кнопок и статусов должны быть лаконичными и умещаться в интерфейсах Minecraft.
5. Выведи строго валидный JSON без комментариев и лишнего текста вокруг.

Исходный файл (en_us.json):
[ВСТАВЬ СОДЕРЖИМОЕ ФАЙЛА en_us.json СЮДА]
```

## Как проверить новый перевод в игре
1. Поместите ваш файл (например, `zh_cn.json`) в `src/main/resources/assets/exchange/lang/` (или в ресурс-пак).
2. Запустите игру.
3. В настройках языка Minecraft (`Настройки` -> `Язык...`) переключитесь на целевой язык.
4. Все терминалы, кошельки, автоматы, планшеты и сообщения чата мгновенно переключатся на выбранный язык!
