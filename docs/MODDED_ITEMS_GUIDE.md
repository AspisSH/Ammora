# Руководство по интеграции кастомных и модовых предметов в биржу ChainBX

Данное руководство объясняет, как легко и сбалансированно добавлять любые предметы из других модификаций (**Create**, **Mekanism**, **Thermal Expansion**, **Botania**, **Applied Energistics 2**, **Farmer's Delight** и др.) на спотовый и деривативный рынок биржи **ChainBX**.

---

## Расположение конфигурационного файла

Файл настроек создается автоматически при первом запуске сервера или клиента:
```text
config/ammora_custom_items.json
```
*(Если файл отсутствует, мод сгенерирует заготовку с примерами латуни, цинка и стали)*.

---

## Структура и параметры предмета

Каждый предмет задается JSON-объектом внутри массива:

```json
[
  {
    "resourceId": "create:brass_ingot",
    "displayName": "Brass Ingot / Латунный слиток",
    "basePrice": 28.0,
    "targetReserve": 6000.0,
    "currentStock": 6000.0,
    "elasticity": 0.85,
    "maxReserve": 10000.0,
    "disposalAlpha": 20.0,
    "feeRate": 0.02,
    "minPriceFloor": 0.20,
    "enabled": true
  }
]
```

### Минимальная конфигурация (Остальное рассчитается автоматически!):
Вам необязательно указывать все поля — движок биржи автоматически подставит математически сбалансированные значения для пропущенных параметров:
```json
{
  "resourceId": "create:brass_ingot",
  "displayName": "Латунный слиток",
  "basePrice": 28.0,
  "targetReserve": 6000.0
}
```

### Описание параметров формулы AMM:
| Параметр | Тип | Описание | Рекомендуемые значения |
| :--- | :--- | :--- | :--- |
| `resourceId` | `String` | Идентификатор предмета в реестре Minecraft (`мод:предмет`). | Обязательно |
| `displayName` | `String` | Отображаемое имя в интерфейсах терминала и уведомлениях. | Опционально |
| `basePrice` | `Double` | Базовая (равновесная) цена в валюте **CBX** при нормальном объеме склада. | От 1.0 до 5000.0+ |
| `targetReserve`| `Double` | Идеальный целевой запас биржи ($S_{target}$). При таком количестве цена = `basePrice`. | 250 - 20000 шт. |
| `currentStock` | `Double` | Начальный склад биржи. Если не указан — равен `targetReserve`. | = `targetReserve` |
| `elasticity` | `Double` | Эластичность кривой цены ($k$). Чем выше, тем резче цена реагирует на дефицит. | `0.75` - `0.95` |
| `maxReserve` | `Double` | Порог переполнения склада ($S_{max}$). При превышении цена падает вплоть до утилизационного сбора. | `targetReserve * 1.5` |
| `disposalAlpha`| `Double` | Коэффициент штрафа утилизации при жестком перепроизводстве. | `15.0` - `30.0` |
| `feeRate` | `Double` | Биржевая комиссия со сделки (0.02 = 2%). | `0.01` - `0.05` |
| `minPriceFloor`| `Double` | Абсолютное ценовое дно (защита от бесконечного падения). | `0.05` - `1.0` |
| `enabled` | `Boolean`| Включен ли предмет (`true`/`false`). | `true` |

## Механика «Изучения образца» (Research Unlock)

Для защиты экономики от спидрана (когда богатый игрок сразу скупает топовые ресурсы из модов, не скрафтив их ни разу), действует система исследований:
1. Базовые ресурсы (**Железо** и **Медь**) открыты всем игрокам со старта.
2. Все остальные ресурсы (Алмазы, Незерит и любые модовые предметы) изначально помечены замком `[Locked]`.
3. Игрок может свободно **продавать** найденные или добытые ресурсы на биржу в любой момент.
4. Чтобы разблокировать возможность **покупки** и торговли деривативами (OMS), игрок нажимает в терминале кнопку:
   `[ИЗУЧИТЬ ОБРАЗЕЦ (1 шт.)]`
   Биржа поглощает 1 образец из инвентаря игрока и навсегда открывает ему доступ к операциям с этим активом.

## Таблица балансировки уровней (Cheat Sheet)

| Уровень (Tier) | Примеры предметов | Базовая цена (`basePrice`) | Целевой склад (`targetReserve`) | Эластичность (`elasticity`) |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: Базовые руды** | Цинк (`create:zinc_ingot`), Олово, Свинец | `10.0 - 15.0 CBX` | `10 000 - 15 000` | `0.75 - 0.80` |
| **Tier 2: Сплавы & Механика** | Латунь (`create:brass_ingot`), Сталь (`mekanism:ingot_steel`), Бронза | `25.0 - 45.0 CBX` | `5 000 - 8 000` | `0.80 - 0.85` |
| **Tier 3: Продвинутые сплавы** | Осмий, Сигналиум, Эндериум, Манасталь | `80.0 - 250.0 CBX` | `1 500 - 3 000` | `0.85 - 0.90` |
| **Tier 4: Высокотехнологичные** | Очищенный обсидиан, Звезда Незера, Террасталь | `500.0 - 2000.0 CBX` | `300 - 800` | `0.90 - 0.95` |
| **Tier 5: Эндгейм компоненты** | Антиматерия, Дракониевые ядра, Творческие детали | `5000.0 - 50000.0 CBX`| `50 - 150` | `0.95` |

## Как применить изменения без перезапуска мира
1. Отредактируйте `config/ammora_custom_items.json`.
2. Перезапустите сервер или одиночный мир. Мод автоматически зарегистрирует новые позиции, а для уже существующих обновит параметры формул, бережно сохранив текущие накопленные запасы игроков!
